## Codebase Patterns
- DB schema lives in lib/db/flag-schema.ts; lib/db/schema.ts re-exports it (auth + flag). drizzle.config.ts points schema at lib/db/schema.ts.
- Migration workflow: `bunx drizzle-kit generate` (creates drizzle/NNNN_*.sql) then `bunx drizzle-kit migrate` to apply. DB is remote Neon via .env.local DATABASE_URL.
- Typecheck: `bunx tsc --noEmit` (no dedicated script). Lint: `bun run lint` (bare eslint).
- Table pattern: pgTable with (table) => [ index(...), unique(...) ] array form. Define a relations() export for each new table and add `many()` on the parent relation.
- Audit logs: entityType/action are free text; environmentId is nullable with no FK (survives env deletion).
